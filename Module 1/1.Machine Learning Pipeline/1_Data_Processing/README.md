# 🔹 1. Data Preprocessing (ML Workflow) 

* **Data preprocessing is the first and most important step in Machine Learning. Raw data is often incomplete, inconsistent, or noisy, so we clean and transform it before building models.**


## 📚 Libraries Used

* **NumPy (Numerical Python)**
  Provides support for fast numerical computations using arrays and matrices. Useful for mathematical operations and data processing.

* **Pandas**
  Used for data manipulation and analysis. Offers powerful data structures like DataFrame and Series to handle structured data efficiently.

* **Matplotlib**
  A visualization library used to create basic plots such as line charts, bar charts, and histograms.

* **Seaborn**
  Built on top of Matplotlib. Used for creating more advanced and visually appealing statistical graphics like heatmaps and distribution plots.
